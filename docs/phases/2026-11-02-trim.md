# 2026-11-02: Trim to what Jude actually uses

## Scope

- **OpenRouter removed.** `OPENROUTER_API_KEY`, `OPENROUTER_MODEL` and `OPENROUTER_EMBEDDING_MODEL`, the OpenRouter structured-call and embedding paths, their error hints and capability note are gone. Bedrock is the only AI provider, and only `AI_PROVIDER=bedrock` enables it (a bare `BEDROCK_MODEL` no longer implies Bedrock). `TRANSCRIBE` is unchanged: on with Bedrock, `1` forces it on, `0` off.
- **Embeddings removed.** Retrieval and evidence-link candidates are keyword-only, as in production. `/capabilities` no longer reports `embeddings`, the evidence graph no longer reports `indexed_passages`, and the `embeddings_partial` notice and its copy are gone. No migration changes: the `embedding`, `embedding_model` and `embedding_vector` columns stay and are simply unused.
- **Synthetic evaluation removed.** `apps/web/evaluation/`, `scripts/evaluate.ts`, `src/lib/server/evaluation.ts`, its test and the `evaluate` script. The live Bedrock benchmarks stay, now defaulting to Nova 2 Lite and Kimi K3, with Claude price rows dropped.
- **Cendana warehouse pack removed** (`examples/cendana-warehouse/` and its ZIP). Nothing imported it; `examples/sambo-796-public/` remains.
- **Voice diarization removed.** The web app only calls `/health` and `/v1/identify`, so `/v1/diarize`, `HF_TOKEN`, `VOICE_DIARIZATION_MODEL` and `VOICE_MAX_RECORDING_SECONDS` are gone. `/v1/embeddings` stays for calibration, and `apps/voice/evaluation/` stays because it still runs on the embedding engine and backs the 0.55 threshold.
- **Tests.** Tests that used OpenRouter as the generic model mock now fake the Bedrock client through `rt.bedrock` with the same assertions. The PostgreSQL test checks keyword retrieval instead of vector sync.
- **Dead code.** Unused exports (`claimSchema`, `LANGS`, `PACK_VALIDITY_MONTHS`, `PlanOutput`) and unused i18n keys (`speakers.title/text/placeholder/save/empty/voices/skeleton`, `dialogue.assistantEmptyTitle/legalLookup/assistantPlaceholder`, `pricing.{lite,pro,kantor}.name`, `pricing.footer.pricing`) removed from both languages.
- **Config files.** `apps/web/.env.example` and `apps/voice/.env.example` list only the variables that are read, grouped, with no commented-out alternatives. Stale comments in `compose.yaml` fixed.

## Verification

- `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm typecheck`, `pnpm test` and `pnpm build` pass in `apps/web`.
- `uv run pytest`, `uv run ruff check .` and `uv run ruff format --check .` pass in `apps/voice`.
- `pnpm test:e2e` passes against a dev server with no AI provider and no Pasal.id key.
